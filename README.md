# Personal Portfolio

## 🚀 How to Run (How to Run)

Follow the steps below to run the project on your local computer:

### 1. Clone the project
```bash
git clone https://github.com/Robiul-Coder007/Personal-Portfolio.git
cd Personal-Portfolio
````

### 2. Create and activate the virtual environment
```bash
# Windows
python -m venv env
env\Scripts\activate

# Mac/Linux
python3 -m venv env
source env/bin/activate
````

### 3. Install the required packages
```bash
pip install -r requirements.txt
````

### 4. Complete the database migration
```bash
python manage.py migrate
````

### 5. Run the server
```bash
python manage.py runserver
````
Now go to browser and visit: `http://127.0.0`
